# Обновления Android

«Склад» проверяет обновления при запуске, после входа и при возврате в приложение.
Повторные фоновые проверки ограничены интервалом в 15 минут.

Сначала клиент запрашивает `http://172.16.4.104/apps/release.json`. Если за 3 секунды
получен корректный манифест «Склада», версия и APK берутся на фабрике. Если ответа нет,
произошёл редирект или манифест некорректен, клиент обращается к
`https://ecad.giulianovars.ru/appsklad/version.php?format=json` с проверкой TLS.
Загрузка идёт из выбранного источника. Установку подтверждает пользователь.

## Публикация

Соберите подписанный APK с увеличенным номером сборки. На каждом выбранном сервере
сначала полностью передайте APK под временным именем и замените им рабочий файл.
Последним атомарно замените JSON с версией. Версия и номер сборки в JSON должны
совпадать с данными внутри опубликованного APK.

* **Фабрика.** Каталог `C:\OSPanel635\home\resursm.ru\apps` на 172.16.4.104.
  Имена файлов — `sklad.apk` (тот же адрес, что в печатном QR-коде) и `release.json`.
  Формат манифеста для сборки 23 приведён ниже. Правила Apache для этого каталога
  находятся в `server/factory-apps/.htaccess`.
* **ECAD.** В каталоге `appsklad` используются `app-release.apk` и `release.json`
  с полями `version` и `build`. Скрипт `version.php` сохраняет прежний формат для
  старых клиентов. Новый клиент также понимает прежний ответ со строкой версии.

```json
{"applicationId":"com.nchauzov.gn.gnsklad","version":"1.0.23","build":23}
```

## Подпись

Существующая release-конфигурация использует debug signing. Она намеренно
сохранена для совместимости с установленными приложениями. Сохраните резервную
копию используемого `%USERPROFILE%\.android\debug.keystore` в защищённом месте
и используйте тот же ключ при переносе сборки на другой компьютер. Не создавайте
новый ключ для уже установленного приложения: Android отклонит обновление.
Не храните ключ в Git. Переход на другой ключ — отдельная задача миграции.

## Установка

Перед запуском установщика проверяются подпись, packageName, версия из записи сервера
и versionCode внутри APK; он должен быть больше установленного. При необходимости
открывается системное разрешение установки из приложения «Склад»; после возврата
скачанный APK открывается без повторного скачивания. Пользователь подтверждает
установку в Android. Успешный запуск установщика не считается подтверждением
завершённой установки. Данные приложения сохраняются при штатном обновлении.

Для перехода с 1.0.23 на фабрике нужно один раз установить подписанную сборку
с выбором источника поверх текущей. Прежняя версия умеет проверять только ECAD.
После публикации нового APK на фабрике для перехода подойдёт прежний QR-код.
