# Обновления Android

Приложение проверяет https://ecad.giulianovars.ru/appsklad/version.php
при запуске, входе пользователя и возвращении в приложение (не чаще раза
в 15 минут при возвращении). Проверки не запускаются параллельно.
APK скачивается с того же сайта, с проверкой HTTPS-сертификата.

## Сервер

Текущий сервер возвращает строку `1.0.13`: новый клиент поддерживает этот
формат, сравнивая части версии как числа. Чтобы обнаруживать также сборки
с прежним названием версии, разместите `server/appsklad/version.php` вместо
старого PHP и рядом `release.json` по примеру `release.example.json`.
Значения должны совпадать с APK: для `version: 1.0.13+13` это version `1.0.13`
и build `13`. Пример не является подтверждением версии опубликованного APK.
Старые приложения получат прежнюю строку, новые — JSON по `?format=json`.
Серверные файлы подготовлены локально, автоматически не опубликованы.

Публикация:
1. Увеличить номер сборки после `+` в pubspec.yaml.
2. Собрать APK с тем же applicationId и тем же ключом подписи.
3. Загрузить APK под временным именем и после окончания загрузки переименовать
   в `app-release.apk`.
4. Последним обновить `release.json`, также через временный файл и переименование.

## Подпись

Существующая release-конфигурация использует debug signing. Она намеренно
сохранена для совместимости с установленными приложениями. Сохраните резервную
копию используемого `%USERPROFILE%\.android\debug.keystore` в защищённом месте
и используйте тот же ключ при переносе сборки на другой компьютер. Не создавайте
новый ключ для уже установленного приложения: Android отклонит обновление.
Не храните ключ в Git. Переход на другой ключ — отдельная задача миграции.

## Установка

Перед запуском установщика проверяется packageName, версия из записи сервера
и versionCode внутри APK; он должен быть больше установленного. При необходимости
открывается системное разрешение установки из приложения «Склад»; после возврата
скачанный APK открывается без повторного скачивания. Пользователь подтверждает
установку в Android. Успешный запуск установщика не считается подтверждением
завершённой установки. Данные приложения сохраняются при штатном обновлении.

Первую сборку с этими исправлениями нужно доставить через старый механизм
или установить вручную поверх текущей. Автообновление после этого использует
новую логику; удалять приложение не нужно.
